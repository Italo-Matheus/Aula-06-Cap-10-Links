Introdução ao MVC

O padrão MVC (Model-Miew-Controller )é uma arguitetura de software untlizada no desenvolvimento de aplicações
para separar a logica de negocios, a interface do úsuario e o controle dos dados. a nterface do usuano e o coutole dos dados

Componentes do MVC

  • Model(Modelo)-Representa os dados e a lógica de negócios da aplicação.
  • View(Visão)-Responsável pela interface com o usuário e exibição de dados.
  • Controller(Controlador)-Intermedia a comunicação entre Model e View.
